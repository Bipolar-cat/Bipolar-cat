​当事者の視点で、生活を助けるシステムを作っています。
<！
-プロジェクト名（step3-summary、step10-summary)
-​🌟 開発の背景
​精神疾患の診察は時間が限られており、体調が悪いときほど自分の状態を正確に伝えるのが難しくなります。私自身の当事者としての経験からまた、今まで出会った当事者の方々から「診察時に何を伝えればいいかわからない」というたくさんの声を聞きました。日々の記録を自動で整理し、可視化することで自身の状態を把握することができ、医師にそのまま見せられる形にまとめるツールを開発しました。
-🏃精神障害者だけでなく健常者など誰でも日々の変化を生活に活かせるように使用してほしいです。
​-✨ 主な機能
​自動要約機能: 日々の記録を「step10」や「step3」の形式で分かりやすく整理します。
​診察用メモの作成: 医師に伝えるべき優先事項を抽出します。
​シンプル操作: 負担を感じず、日常的に使い続けられる設計を目指しています。
